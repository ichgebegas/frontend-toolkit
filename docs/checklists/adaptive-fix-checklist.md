# Adaptive Fix Checklist

Проверять каждый компонент и solution перед публикацией.

## Ширины

- 320 px
- 375 px
- 768 px
- 1024 px
- 1440 px

## Что проверить

- Нет горизонтального скролла.
- Меню не ломается.
- Текст не вылезает из контейнеров.
- Кнопки кликабельны и не слишком мелкие.
- Отступы выглядят спокойно.
- Формы и карточки не давят визуально.
- Интерактивные элементы работают мышью и клавиатурой там, где это уместно.
