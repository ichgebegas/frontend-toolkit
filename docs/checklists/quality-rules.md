# Quality Rules

- Не расширять v1 сверх утвержденного набора.
- Не делать ручные `preview.png` до готовности блоков.
- Не добавлять внешние зависимости.
- Не превращать блоки в идеальные дизайн-макеты.
- Использовать только легкие micro-interactions: hover, active, focus-visible, transition.
- Не добавлять сложные анимации, scroll effects и сторонние animation-библиотеки.
- Улучшения вне текущего релиза переносить в `TODO_v1.1.md`.
