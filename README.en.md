# Frontend Toolkit

[Русская версия](README.md)

A library of reusable UI blocks and practical solutions for commercial websites.  
The project is designed as a working catalog: find a useful interface, inspect it across viewport sizes, and reuse it in another project.

**Live demo:** [ichgebegas.github.io/frontend-toolkit](https://ichgebegas.github.io/frontend-toolkit/)

## Features

- UI catalog grouped by category;
- live component previews;
- desktop, tablet, and mobile viewport switching;
- background pattern library;
- search across categories and components;
- light and dark themes.

## Structure

- `showcase/` - React catalog deployed with GitHub Pages;
- `components/` - standalone HTML/CSS/JS examples;
- `solutions/` - reusable interactive solutions;
- `snippets/` - CSS helpers and background patterns;
- `docs/` - checklists and component transfer notes.
