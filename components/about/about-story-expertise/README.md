# About Story Expertise

Готовый About-блок, адаптированный под автономный HTML/CSS пример.

## Copy Guide

1. Скопируй секцию из `index.html`.
2. Перенеси `style.css`.
3. Замени reference-media своими изображениями перед публичной публикацией.
4. Проверь адаптив на ширинах 320, 375, 768, 1024 и 1440 px.
