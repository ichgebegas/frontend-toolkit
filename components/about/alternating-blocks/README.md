# Alternating Blocks

Готовый About-блок для истории компании с чередованием текста и изображения.

## Copy Guide

1. Скопируй секцию `.about-alternating` из `index.html`.
2. Подключи или перенеси `style.css`.
3. Перенеси папку `assets/` или замени изображения своими.
4. Проверь адаптив на ширинах 320, 375, 768, 1024 и 1440 px.

## Источник идеи

Структура и demo-copy основаны на открытом примере `Alternating Blocks` из OpenSite UI. Реализация адаптирована под автономный HTML/CSS пример без React, Tailwind и внешних зависимостей.

Изображения сохранены локально из reference-demo для визуальной сверки. Перед публичной публикацией библиотеки замени их своими файлами или отдельно подтверди право на распространение.

Лицензионная информация для адаптированного OpenSite-кода указана в `../../../THIRD_PARTY_NOTICES.md`.
