# Blog

Категория содержит 13 автономных Blog-примеров, перенесенных из source-структуры OpenSite и адаптированных под визуальные tokens Toolkit.

## Copy guide

1. Скопируй разметку нужного `index.html`.
2. Подключи общий `../blog-base.css` и локальный `style.css`.
3. Для `blog-filtered-results` и `blog-carousel-apple` также подключи локальный `script.js`.
4. Проверь desktop и mobile состояния, изображения и интерактивы перед переносом в проект.

Подробный контроль переноса находится в `docs/transfer-guides/blog-source-gate.md`.
