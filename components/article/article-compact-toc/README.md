# Article Compact TOC

Компактная статья с mobile-friendly раскрывающимся оглавлением.

## Copy Guide

1. Скопируй секцию `.compact-toc` из `index.html`.
2. Подключи `../article-base.css`, `style.css`, `../../../snippets/patterns.css` и `script.js`.
3. Свяжи пункты оглавления с `id` заголовков статьи.
4. Проверь раскрытие TOC, `aria-expanded` и mobile overflow.

## Источник Идеи

Структура и поведение основаны на открытом примере `Article Compact TOC` из OpenSite UI и реализованы без внешних зависимостей.
