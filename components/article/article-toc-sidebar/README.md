# Article TOC Sidebar

Длинная статья с desktop sticky-оглавлением, CTA и отслеживанием активного раздела.

## Copy Guide

1. Скопируй секцию `.article-toc` из `index.html`.
2. Подключи `../article-base.css`, `style.css`, `../../../snippets/patterns.css` и `script.js`.
3. Сопоставь ссылки `.toc-link` с реальными `id` заголовков.
4. Проверь sticky на desktop и обычный порядок контента на mobile.

## Источник Идеи

Структура и поведение основаны на открытом примере `Article TOC Sidebar` из OpenSite UI и реализованы на vanilla JS.
