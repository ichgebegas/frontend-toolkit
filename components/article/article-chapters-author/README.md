# Article Chapters Author

Guide-layout с нумерованными главами, профилем автора и conclusion CTA.

## Copy Guide

1. Скопируй секцию `.chapters-author` из `index.html`.
2. Подключи `../article-base.css`, `style.css` и `script.js`.
3. Обнови главы, данные автора и CTA.
4. Проверь active chapter tracking и порядок sidebar на mobile.

## Источник Идеи

Структура и поведение основаны на открытом примере `Article Chapters Author` из OpenSite UI и адаптированы для vanilla JS.
