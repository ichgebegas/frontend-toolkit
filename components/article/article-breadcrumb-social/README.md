# Article Breadcrumb Social

Статья с breadcrumb, sharing controls, оглавлением и back-to-top.

## Copy Guide

1. Скопируй секцию `.breadcrumb-social` из `index.html`.
2. Подключи `../article-base.css`, `style.css` и `script.js`.
3. Обнови breadcrumbs, ссылки разделов и данные автора.
4. Проверь active TOC и появление кнопки возврата после прокрутки.

## Источник Идеи

Структура и поведение основаны на открытом примере `Article Breadcrumb Social` из OpenSite UI и адаптированы для vanilla JS.
