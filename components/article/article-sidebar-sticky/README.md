# Article Sidebar Sticky

Статья с закрепленной на desktop карточкой автора и ссылкой возврата.

## Copy Guide

1. Скопируй секцию `.sidebar-sticky` из `index.html`.
2. Подключи `../article-base.css` и `style.css`.
3. Подставь текст, автора и hero-изображение.
4. Проверь, что на mobile sidebar возвращается в обычный поток.

## Источник Идеи

Структура основана на открытом примере `Article Sidebar Sticky` из OpenSite UI и адаптирована для vanilla HTML/CSS.
