# Article Split Animated

Featured article preview с split-layout, media и основным CTA.

## Copy Guide

1. Скопируй секцию `.split-article` из `index.html`.
2. Подключи `../article-base.css` и `style.css`.
3. Замени изображение, метаданные автора и CTA.
4. Проверь перестроение split-layout в одну колонку на mobile.

## Источник Идеи

Структура основана на открытом примере `Article Split Animated` из OpenSite UI; motion-поведение сознательно упрощено до переносимого vanilla-варианта.
