# Article Hero Prose

Центрированный long-form article с hero-изображением, автором и rich prose.

## Copy Guide

1. Скопируй секцию `.hero-prose` из `index.html`.
2. Подключи `../article-base.css`, `style.css` и `../../../snippets/patterns.css`.
3. Замени текст, автора и изображения своими source-backed данными.
4. Проверь адаптив на 320, 375, 768, 1024 и 1440 px.

## Источник Идеи

Структура основана на открытом примере `Article Hero Prose` из OpenSite UI и адаптирована под автономный HTML/CSS без React и Tailwind.
