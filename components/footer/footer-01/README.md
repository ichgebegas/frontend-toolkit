# Footer 01

Готовый автономный пример для библиотеки Frontend Toolkit v1.

## Как скопировать

1. Скопируй нужную секцию из `index.html`.
2. Подключи или перенеси `style.css`.
3. Подключи `script.js`, если файл есть.
4. Проверь адаптив по чеклисту: 320, 375, 768, 1024, 1440 px.

## Примечание

Шаблон специально сделан простым: это рабочая основа, а не финальная полировка под конкретный бренд.
