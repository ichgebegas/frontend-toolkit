# Frontend Toolkit

[English version](README.en.md)

Библиотека готовых UI-блоков и практических решений для коммерческих сайтов.  
Проект создан как рабочая витрина: нужный интерфейс можно найти, открыть в нескольких разрешениях и перенести в новый проект.

**Live demo:** [ichgebegas.github.io/frontend-toolkit](https://ichgebegas.github.io/frontend-toolkit/)

## Возможности

- каталог UI-блоков по категориям;
- отдельные страницы компонентов с live preview;
- переключение desktop, tablet и mobile;
- библиотека фоновых паттернов;
- поиск по категориям и компонентам;
- светлая и темная темы.

## Структура

- `showcase/` - React-витрина, опубликованная через GitHub Pages;
- `components/` - автономные HTML/CSS/JS-примеры;
- `solutions/` - переносимые интерактивные решения;
- `snippets/` - CSS-заготовки и фоновые паттерны;
- `docs/` - чеклисты и заметки по переносу компонентов.

## Локальный запуск

```bash
cd showcase
npm install
npm run dev
```

Открой [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Сборка

```bash
cd showcase
npm run build
```
