# Frontend Toolkit

Практичная HTML/CSS/JS библиотека UI-решений для коммерческих лендингов услуг.

## Что внутри

- `components/` — 10 секций по 3 автономных варианта.
- `solutions/` — интерактивные решения на vanilla JS.
- `snippets/` — базовые CSS-заготовки.
- `demo/` — витрина для просмотра всех вариантов.
- `docs/checklists/` — чеклисты качества и адаптива.

## Как использовать

1. Открой нужный пример через `index.html`.
2. Скопируй секцию из HTML.
3. Перенеси `style.css`.
4. Подключи `script.js`, если он есть.
5. Проверь адаптив на 320, 375, 768, 1024 и 1440 px.
